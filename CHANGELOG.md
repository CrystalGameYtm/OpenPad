# Changelog

## 0.2.0 — листопад 2026
* Ремапінг геймпад → клавіші клавіатури й миші (`KEY_*`, `MOUSE_*`), віртуальна клавіатура (uinput / SendInput).
* Режим D-pad як кнопки (`dpad_mode: "buttons"`).
* Вібрація: DS4 по Bluetooth (звіт `0x11` + CRC-32), `rumble-test`, `sdl-rumble`.
* Гіроскоп: живі °/с в UI, калібрування нуля (`gyro.bias`).
* Web UI: вкладка «Протокол» (опис протоколу, режим пристрою, вихідний протокол, приховування оригіналу); ML/MR прибрано з UI.
* Вихідний протокол на пристрій: емуляція XInput (рекомендовано), штатний DS4 / DInput (експериментально, з попередженнями).
* Приховування оригіналу переписано: закриваються всі вузли фізичного пристрою (hidraw/event/js) з обліком і відновленням;
  `setup-hide`, `unhide`, `sdl-list`, `serve --privileged`.
* Linux: udev-правила для Bluetooth hidraw, дружні повідомлення й backoff при відсутності прав.
* Windows (базово, без перевірки на залізі): ViGEm, SendInput, HidHide, вбудований WinAPI HID-backend без hidapi.

## 0.1.0
* Перший публічний стан: hidraw/evdev/hidapi → uinput, розкладки, калібрування, Web UI, профілі, udev.
